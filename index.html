Minority Game Simulator

エージェント数と記憶長を設定し、 マイノリティゲームの混雑と効率性を観察します。

ゲームの構造

Players

N人のエージェントが同時にゲームへ参加します。 少数派を必ず決定できるよう、Nは奇数とします。

Actions

各エージェントは毎期、 0または1のどちらかを選択します。

Payoff

結果 利得
少数派 1
多数派 0

Memory

各エージェントは、直近m期の 少数派だった選択の履歴を記憶します。 履歴は次の行動を決める情報として使われます。

Strategies

各エージェントは2つの戦略を持ちます。 各戦略は、過去m期の履歴ごとに 0または1のどちらを選ぶかを定めています。

Learning

使用しなかった戦略も含めて毎期仮想得点を更新し、 より高い得点を持つ戦略を使って 次の行動を決定します。

パラメータの意味

エージェント人数 N

ゲームに参加するエージェントの人数です。 少数派を必ず決定できるよう、奇数に設定します。

記憶長 m

各エージェントが参照する、 過去の少数派履歴の長さです。 mが大きいほど、参照できる履歴パターンが増えます。

α = 2m / N

記憶可能な履歴パターン数と エージェント人数の比を表す指標です。

αを変えることで、 集団の混雑や効率性がどのように変化するかを観察できます。

結果の読み方

α

α = 2m / N で定義される指標です。 記憶可能な履歴パターン数と、 エージェント人数のバランスを表します。

σ²

1を選んだ人数が、 N / 2 からどれだけ変動したかを表します。 値が大きいほど、0と1への集中が大きいことを意味します。

σ² / N

σ²をエージェント人数Nで正規化した指標です。 異なる人数のゲームでも、 集団の効率性を比較しやすくなります。

ポイント

σ² / N が小さいほど、 0と1の人数が均等に近く、 多くのエージェントが少数派として勝てるため、 集団全体として効率的な状態と解釈できます。
